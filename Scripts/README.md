# Система выполнения SQL-скриптов

Данная папка содержит SQL-скрипты, которые автоматически выполняются при запуске приложения.

## Как это работает

1. При запуске приложения система `DatabaseScriptService` сканирует папку `Scripts/`
2. Находит все файлы с расширением `.sql`
3. Сортирует их по имени в алфавитном порядке
4. Проверяет, какие скрипты еще не выполнены (по записям в таблице `DatabaseScripts`)
5. Выполняет новые скрипты в транзакциях
6. Записывает информацию о выполнении в таблицу `DatabaseScripts`

## Соглашения о наименовании

Рекомендуется использовать следующий формат имен файлов:
```
001_DescriptiveName.sql
002_AnotherScript.sql
003_FixSomething.sql
```

Где:
- `001`, `002`, `003` - порядковый номер (обеспечивает правильную сортировку)
- `DescriptiveName` - описательное имя скрипта

## Структура скрипта

```sql
-- Комментарий с описанием того, что делает скрипт
-- UP: Описание изменений

-- SQL команды здесь
CREATE TABLE example (...);
ALTER TABLE existing_table ADD COLUMN new_column VARCHAR(100);
```

## Особенности

- **Идемпотентность**: Используйте `IF NOT EXISTS`, `IF EXISTS` и подобные конструкции
- **Транзакции**: Каждый скрипт выполняется в отдельной транзакции
- **Хэширование**: Система отслеживает изменения содержимого скрипта через SHA256
- **Логирование**: Все операции логируются в систему логирования Serilog
- **Обработка ошибок**: При ошибке выполнения информация сохраняется в БД

## Мониторинг

Для просмотра выполненных скриптов выполните запрос:
```sql
SELECT * FROM "DatabaseScripts" ORDER BY "ExecutedAt" DESC;
```

## Примеры скриптов в папке

- `001_FixRowVersionFields.sql` - исправление полей RowVersion для PostgreSQL
- `002_CreateIndexes.sql` - создание индексов для оптимизации производительности
